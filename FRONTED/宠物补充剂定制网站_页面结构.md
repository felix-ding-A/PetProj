# 宠物补充剂定制网站 · 页面结构

> 项目定位：B2B 宠物补充剂 OEM/ODM 代工厂获客站（招品牌方 / 贴牌买家，非零售商城）
> 结构参考：Prosafenutra 三套并行页面体系 + 宠物赛道专属的"物种 × 功能"维度
> 剂型（5 类）：咀嚼片 / 胶囊 / 粉剂 / 滴剂 / 膏剂
> 编制日期：2026-11-23

---

## 1. 架构总览

全站由 **4 套页面体系** + **多语言镜像**构成：

| 体系 | URL 前缀 | 作用 | 页面级别 |
|---|---|---|---|
| ① 核心页面 | 根路径 | 品牌信任 + 服务能力 + 询盘收口 | 人工精写，P0/P1 |
| ② 白牌产品目录 | `/private-label/` | 具体产品落地页，接长尾词 | 半程序化，P1/P2 |
| ③ 定制配方库 | `/custom-formulation/` | 剂型 × 功效 × 物种 矩阵，抢覆盖面 | 程序化，P2 |
| ④ 内容中心 | `/insights/` | SEO 引流 + 品类教育 | 人工撰写，P2 |

> 多语言：先做 EN；按目标市场再镜像（参考站为 EN/FR/DE/ES/JA），URL 前缀 `/{lang}/`。

## 4. 页面模板（各类页面的 section 结构）

### 4.1 首页 `/`

```
Hero（定位句 + 信任状 + 双 CTA）
→ 数据条（MOQ / 交期 / 工厂数 / 配方数）
→ 5 大剂型能力入口（卡片，链到制造页）
→ Why Choose Us（信任支撑）
→ 定制流程 5 步（摘要，链到 /our-process/）
→ 质量与合规（摘要，链到 /quality-compliance/）
→ 全球产能与布局
→ 认证
→ 客户案例
→ 产品目录入口（链到 /private-label/）
→ 博客最新 3 篇
→ FAQ（摘要）
→ 底部 CTA → 询盘
```

### 4.2 剂型制造页（5 个，套同一模板）

```
1. Hero        剂型名 + 一句话能力 + [Get a quote] [View products]
2. Why us      为什么选我们做这个剂型（2-3 个技术卖点）
3. 定制能力     壳材/规格/外形/包衣等技术选项（体现专业度）
4. 5 步流程     配方兼容性 → 混合 → 成型 → 干燥/抛光 → QC 检测出 COA
5. 规格表       Materials ｜ Formats ｜ MOQ ｜ 成熟配方（按功能分）
6. 质量标准     AI 研发 / 制药级 / 可追溯（全站复用三段）
7. 工厂图集 + 认证
8. 成熟配方清单  按功能分组，链到对应产品落地页
9. FAQ          该剂型专属 6 问
10. 其他剂型互链 + CTA
```

> 五个剂型技术段差异化重点：
> - 咀嚼片：诱食 + 掩味 + 硬度/脆碎度
> - 胶囊：壳材 + 肠溶 + 避光
> - 粉剂：载体 + 粒度 + 防潮 + 拌粮接受度
> - 滴剂：滴管/泵头精度 + 油相均质 + 氮封
> - 膏剂：乳化稳定 + 油脂析出控制 + 软管灌装

### 4.3 产品落地页 `/private-label/{剂型}/{产品slug}/`

```
产品名 + 一句成分功效描述
→ 关键成分与规格
→ 适用物种 / 功能方向
→ 剂型与包装选项
→ MOQ / 交期
→ [Get a quote] CTA
→ 同剂型其他产品（互链）
```

### 4.4 定制配方库页（维度页 / 交叉页）

```
维度名（如 joint / dogs / ingredient X）
→ 该维度下的配方清单（卡片，链到交叉页）
→ 相关功效 / 物种 / 剂型 交叉链接
→ [Request custom formulation] CTA
```

### 4.5 询盘页 `/contact-us/`（6 段式表单）

```
1. 基本信息：姓名 / WhatsApp / 邮箱 / 国家 / 公司
2. 配方状态：自有完整配方 / 需优化 / 有参考产品 / 只有想法
3. 剂型与数量：咀嚼片·胶囊·粉剂·滴剂·膏剂（多选）+ 目标数量区间
4. 目标宠物与功能：猫 / 狗 / 小宠；关节 / 皮毛 / 肠胃 / 免疫 / 驱虫…
5. 规格文档上传 + 关键成分与添加量
6. 合规要求：目标市场（EU / US / 中国）、是否需要宠物饲料相关文件
```

## 5. 内链逻辑

- 首页 → 5 剂型页 + 关于 + 询盘
- 剂型页 → 白牌目录对应剂型 + 其他 4 剂型互链 + 询盘
- 产品目录页 → 产品落地页 + 询盘
- 产品落地页 → 询盘 + 同剂型其他产品
- 配方库维度页 → 交叉组合页 + 询盘
- 博客文章 → 相关产品页 / 配方页 + 询盘
- **全站所有页面 → 询盘页（唯一转化终点）**
